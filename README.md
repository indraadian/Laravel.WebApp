# Laravel WebApp

Project ini adalah aplikasi web sederhana berbasis **Laravel** yang mendemonstrasikan:

- ✨ CRUD (Create, Read, Update, Delete) menggunakan **Eloquent ORM**
- 🌍 **Localization** (multi bahasa: EN & ID)
- 🎨 **Theme switcher** (Dark / Light mode)

---

## 🚀 Fitur

- **CRUD**: Contoh implementasi CRUD untuk entitas (misalnya: Post, Product, atau User).  
- **ORM**: Menggunakan **Eloquent ORM** untuk interaksi database.  
- **Localization**: Mendukung perubahan bahasa (default: `en`, alternatif: `id`).  
- **Theme Switcher**: User dapat memilih dark mode atau light mode, disimpan di session.  

---

## ⚙️ Tech Stack

- [Laravel](https://laravel.com/) 10.x / 11.x
- Eloquent ORM
- Blade Template Engine
- TailwindCSS (opsional untuk styling)
- MySQL / SQLite (sesuaikan)
